Ohjelma on flash viesteillä toimiva local-host kirjoitusvirheidenkorjaaja. Kun avaat sovelluksen esiin tulee tekstilaatikko, johon voi kirjoittaa tekstiä. Kun painat lähetä, ohjelma antaa ehdotuksia mahdollisesti väärinkirjoitetuille sanoille, jos ehdotuksia löytyy.

Lataa projektin riippuvuudet komennolla 
```bash
poetry install
```

Siirry virtuaaliympäristöön ja aja index.py komentorivissä src kansiosta

Windowsilla tämä toimii komennolla 
```bash
py index.py
```

Avaa selaimessa local-host server http://127.0.0.1:5001
